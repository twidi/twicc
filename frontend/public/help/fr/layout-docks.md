Vous venez d'envoyer un onglet vers une **zone d'ancrage** — l'une des régions autour de la
session. C'est ainsi que vous composez votre propre disposition : gardez la conversation au
centre et épinglez **Fichiers**, **Git**, **Terminal**, **Artefacts** — n'importe quel onglet — où
bon vous semble.

- Utilisez le **chevron (▾)** de n'importe quel onglet pour l'ancrer dans une zone (gauche,
  droite, bas) ou le ramener au centre.
- Faites glisser le séparateur entre les régions pour redimensionner une zone. Réduisez une
  zone pour la replier, puis restaurez-la quand vous en avez besoin.
- Votre arrangement est mémorisé **par session**. Vous le retrouvez à votre retour.

### Enregistrez-la et réutilisez-la

Les dispositions se trouvent dans le **menu ⋮**, à l'extrémité droite de la barre d'onglets :

- **Enregistrer la disposition** stocke votre arrangement actuel sous forme de disposition
  nommée — une nouvelle, ou en remplacement d'une existante.
- Le même menu liste vos dispositions enregistrées (et **Panneau unique**). Vous pouvez ainsi
  appliquer l'une d'elles à n'importe quelle session en un clic. Il propose aussi
  **Gérer les dispositions…** pour les renommer ou les supprimer.

### Définir une disposition par défaut pour les nouvelles sessions

Dans la boîte de dialogue d'enregistrement, cochez **Définir par défaut pour les
nouvelles sessions** pour chaque portée — elles sont indépendantes :

- **Global** — chaque nouvelle session, partout.
- **Ce projet** — uniquement les nouvelles sessions de ce projet.
- **Ce worktree** — uniquement les nouvelles sessions de ce worktree (quand vous êtes dans
  l'un d'eux).

Une nouvelle session prend la valeur par défaut **la plus spécifique** qui s'applique
(worktree → projet → global). Vous pourrez aussi les modifier plus tard : la valeur globale
dans **Paramètres → Dispositions**, et celle d'un projet (ou d'un worktree) dans sa boîte de
dialogue de modification.
