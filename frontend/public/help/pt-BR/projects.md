Um projeto é um **diretório de trabalho** onde as sessões dos agentes são executadas — um projeto por
pasta. O TwiCC cria um automaticamente para cada pasta que contém sessões,
incluindo sessões que você executa com Claude Code ou Codex **fora** do TwiCC. Você
também pode adicionar um projeto ao indicar uma pasta ao TwiCC.

### O que o TwiCC mantém em um projeto

Cada sessão executada nessa pasta fica agrupada no projeto. Assim, você pode
encontrar seu trabalho pelo local onde ele ocorre.

### Abrir um projeto

Abra a **página inicial** de um projeto ao clicar nele na página inicial ou no
seletor de projetos no topo da barra lateral — mesmo se ele já estiver selecionado. Dentro de uma
sessão, o nome do projeto no cabeçalho leva você de volta à página do projeto.

Para renomear um projeto ou alterar suas configurações, abra o menu **⋮** dele, na página inicial ou
no seletor de projetos, e escolha **Editar**.

### Personalizar

Dê um **nome** e uma **cor** ao projeto. Defina **configurações padrão por projeto**
(provedor, configurações do agente e layout padrão) para cada nova sessão que você iniciar
nele.

O nome também organiza a lista inicial: projetos **com nome** aparecem no topo como cartões,
para facilitar o acesso aos mais importantes. Os projetos **sem nome** aparecem abaixo,
agrupados em uma árvore de pastas por seus caminhos.

### Organizar

Agrupe projetos relacionados em um [espaço de trabalho](help/workspaces). Os
[worktrees](help/worktrees) de um repositório git aparecem como projetos próprios, vinculados a ele.
Assim, a página de um projeto também lista as sessões dos seus worktrees, com um indicador para diferenciar
as sessões do projeto principal e dos worktrees.

### Arquivar

Terminou de trabalhar em um projeto? Use **Arquivar** para ocultá-lo das listas. Nada é
excluído, e suas sessões continuam disponíveis na pesquisa. Arquive-o no diálogo de edição ou
no menu **⋮** do seletor de projetos no topo da barra lateral. Para ver
os projetos arquivados novamente, marque **Mostrar arquivados** na seção Projetos da página inicial.
Nessa seção, você pode **desarquivar** qualquer um deles.
