Lege unter **Einstellungen → Allgemein → Vorlage für das Worktree-Verzeichnis** fest, wo neue Worktrees entstehen.

Zum Beispiel hält `{git_root}/.worktrees` sie im jeweiligen Repository. Im Bearbeiten-Dialog eines Projekts kannst du ein anderes Verzeichnis festlegen.

Die verfügbaren Platzhalter stehen unter [Mit Worktrees arbeiten](help/worktrees).
