Configura **Configuración → General → Plantilla del directorio de worktrees** para elegir dónde crear los nuevos worktrees.

Por ejemplo, `{git_root}/.worktrees` los mantiene dentro de cada repositorio. Puedes definir otro directorio en el cuadro de diálogo de edición del proyecto.

Consulta [Trabajar con worktrees](help/worktrees) para ver los marcadores disponibles.
