La terminal no se limita a un solo shell. Usa **+** para abrir más pestañas
(haz doble clic en una pestaña para renombrarla) y conecta terminales compartidas con alcance de
**Proyecto**, **Espacio de trabajo** o **Global**, útiles para comandos de larga duración
a los que quieres acceder desde cualquier sesión.

Activa **Configuración → Terminal → Sesiones persistentes (tmux)** para mantener tus
terminales activas tras recargar y reconectar; se limpian cuando se archiva su
sesión.
