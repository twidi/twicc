Modifiez les **paramètres de l'agent** d'une session en cours (modèle, effort, mode d'autorisation
et plus encore) depuis la fenêtre contextuelle à côté de **Envoyer**.

Si vous ajustez un paramètre sans saisir de message, le bouton **Envoyer** devient
**Appliquer les paramètres** : cliquer dessus envoie uniquement cette modification. Certains paramètres
prennent effet immédiatement ; d'autres s'appliquent à partir de votre prochain message.
