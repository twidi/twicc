Dans n'importe quel diff ou affichage de code (un Edit dans le chat, l'onglet Fichiers, un commit Git),
survolez un numéro de ligne et cliquez sur le **+** dans la gouttière pour attacher une note à
cette ligne précise.

Vos notes apparaissent sous forme d'indicateurs sur les messages et les commits concernés. Utilisez **Ajouter
au message** pour déposer un commentaire (avec sa ligne) dans la zone de saisie, ou ajoutez-les
tous d'un coup.
