Définissez **Paramètres → Général → Template de répertoire des worktrees** pour choisir où créer les nouveaux worktrees.

Par exemple, `{git_root}/.worktrees` les garde dans chaque dépôt. Vous pouvez définir un autre répertoire dans la boîte de dialogue de modification du projet.

Consultez [Travailler avec les worktrees](help/worktrees) pour les variables disponibles.
