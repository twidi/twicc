Dans **Navigateur**, cliquez sur l'**icône en forme de pointeur** dans la barre d'outils, puis sur un élément. Ajoutez votre commentaire.

Pour un artefact HTML, cette icône se trouve dans le **menu des outils** en haut à droite de l'aperçu.

Les pages du navigateur nécessitent le script compagnon : consultez [L'onglet Navigateur](help/browser-tab).
