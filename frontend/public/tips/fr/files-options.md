Dans l'onglet **Fichiers**, affichez les **fichiers cachés** ou **ignorés par Git**, activez
**Ouverture automatique** pour prévisualiser les fichiers en parcourant l'arborescence avec les flèches, ou utilisez **Faire défiler
jusqu'au fichier sélectionné** pour repérer le fichier que vous consultez.

Vous les trouverez avec le bouton à gauche du champ **Filtrer les fichiers**.
