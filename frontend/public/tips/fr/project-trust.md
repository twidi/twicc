Claude Code et Codex ont chacun leur propre indicateur de *projet approuvé*. TwiCC le gère en un
seul endroit : la première session d'un nouveau projet pose la question une fois, enregistre la
décision pour les deux fournisseurs, et peut l'appliquer aux sous-répertoires et aux worktrees.

Les projets démarrent non approuvés, ce qui désactive les modes à accès complet (« Contourner les autorisations » de Claude, Yolo de Codex). Vous pouvez définir le mode d'autorisation utilisé sur les projets non approuvés —
lecture seule, par exemple — dans les paramètres de votre fournisseur. L'accès complet se
débloque dès que vous approuvez le projet.
