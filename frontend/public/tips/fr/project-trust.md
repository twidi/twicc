La première session d'un nouveau projet vous demande de l'**approuver**. TwiCC enregistre votre décision pour Claude Code et Codex.

Les projets non approuvés désactivent les modes à accès complet. Approuvez un projet pour débloquer le contournement des autorisations de Claude et Yolo de Codex.

Choisissez le mode d'autorisation des projets non approuvés dans les paramètres du fournisseur.
