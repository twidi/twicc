Vous préférez les déplacements par mot de style Emacs dans votre shell ? Dans **Paramètres → Terminal**,
activez **Touche Option (⌥) → Utiliser comme touche Meta** pour que **⌥B / ⌥F** se déplacent mot par mot (et que
**⌥.** insère le dernier argument).

Le compromis : les caractères saisis avec Option, comme `|`, `{` ou `\` sur certaines
dispositions de clavier, ne fonctionnent plus. Laissez donc cette option désactivée si vous en avez besoin.
