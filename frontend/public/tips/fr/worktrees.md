Cliquez sur le bouton **Nouvelle session** : les projets git de la liste affichent un bouton
de worktree (une icône de branche avec un **+**). Cliquez dessus pour créer un worktree git, sur une
branche nouvelle ou existante, et ouvrir une session directement dedans.

Le worktree est automatiquement lié à son projet parent, de sorte que ses sessions
sont regroupées sous le dépôt principal.

Plus de détails dans la fenêtre d'aide : [Travailler avec les worktrees](help/worktrees).
