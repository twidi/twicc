Em qualquer visualização de código ou diff, passe o cursor sobre um número de linha.
Isso inclui uma edição no chat, a aba Arquivos ou um commit do Git.
Clique no **+** na margem para adicionar uma nota àquela linha.

Suas notas aparecem como indicadores nas mensagens e nos commits correspondentes.
Use **Adicionar à mensagem** para inserir um comentário, com sua linha, no campo de mensagem.
Você também pode adicionar todos os comentários de uma vez.
