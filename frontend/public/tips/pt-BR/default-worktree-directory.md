Defina **Configurações → Geral → Template de diretório de worktrees** para escolher onde criar novos worktrees.

Por exemplo, `{git_root}/.worktrees` mantém os worktrees dentro de cada repositório. Você pode definir outro diretório no diálogo de edição do projeto.

Veja os placeholders disponíveis em [Trabalhar com worktrees](help/worktrees).
