Na aba **Arquivos**, mostre **arquivos ocultos** ou **arquivos ignorados pelo Git**.
Ative **Abrir automaticamente** para pré-visualizar os arquivos enquanto usa as setas para navegar pela árvore.
Ou use **Rolar até o arquivo selecionado** para localizar o arquivo que você está visualizando.

Acesse essas opções pelo botão à esquerda do campo **Filtrar arquivos**.
