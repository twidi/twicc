Pressione **Cmd+F** — ou clique no ícone de lupa no cabeçalho da sessão —
para pesquisar texto na conversa atual. Isso substitui a pesquisa do navegador.
Pressione **Cmd+F** novamente para usar a pesquisa do navegador.

Use **F3** / **Shift+F3** para percorrer os resultados e **Esc** para fechar. Para pesquisar
em todas as sessões, pressione **Cmd+Shift+F**.
