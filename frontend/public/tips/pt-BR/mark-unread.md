Sessões com novas atividades mostram um indicador de conteúdo não lido na barra lateral:
um olho laranja.

Abra o menu **⋮** ao lado do nome de uma sessão para **Marcar como não lido**.
Isso serve como lembrete para voltar depois. Use **Marcar como lido** para remover o indicador
sem abrir a sessão.
