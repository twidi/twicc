Sessões com novas atividades mostram um indicador de conteúdo não lido na barra lateral:
um olho laranja.

Abra o menu **⋮** ao lado do nome de uma sessão para **Marcar como não lida**.
Isso serve como lembrete para voltar depois. Use **Marcar como lida** para remover o indicador
sem abrir a sessão.
