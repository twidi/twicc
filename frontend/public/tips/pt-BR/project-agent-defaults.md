Você escolhe sempre o mesmo modelo e modo de permissão para cada nova sessão? No diálogo
de edição do projeto, abra a aba **Configurações do agente** e defina um provedor,
modelo, esforço e outras configurações padrão.

Cada nova sessão nesse projeto começa com essas configurações. Os worktrees herdam
as configurações padrão do repositório principal. Use **Carregar de…** para copiar uma predefinição ou
as configurações de outro projeto.
