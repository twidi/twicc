Cada projeto tem sua própria página. A aba **Linha do tempo** lista os eventos conforme ocorrem (criação de sessões,
turnos, aprovações, alterações de nome...). A aba **Estatísticas** mostra informações sobre a atividade
(e os custos, quando **Mostrar custos** está ativado). As abas **Arquivos**, **Git**
e **Terminal** do projeto não estão vinculadas a uma sessão específica.

Para abrir essa página a partir de uma sessão, clique no **nome do projeto** no **canto superior direito
do cabeçalho**. Na tela inicial, basta clicar em um projeto.
