A primeira sessão de um projeto novo pergunta se você **confia no projeto**. O TwiCC salva sua decisão para Claude Code e Codex.

Projetos não confiáveis desativam os modos de acesso total. Confie no projeto para liberar Ignorar permissões do Claude e Yolo do Codex.

Escolha o modo de permissão dos projetos não confiáveis nas configurações do provedor.
