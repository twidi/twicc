A seleção múltipla permite arquivar, fixar ou parar várias sessões de uma vez.

Ative-a pelo botão à esquerda do campo **Filtrar sessões**. Depois, use Shift-click
ou Cmd/Ctrl-click para selecionar sessões. Para agilizar, com uma sessão aberta, use Shift-click
em outra para selecionar um intervalo e ativar a seleção múltipla automaticamente.
