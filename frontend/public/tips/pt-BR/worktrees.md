Clique no botão **Nova sessão** — os projetos Git na lista mostram um botão de worktree
(um ícone de branch com **+**). Clique nele para criar um worktree do Git em uma
branch nova ou existente e abrir uma sessão diretamente nele.

O worktree é vinculado automaticamente ao projeto principal, para que suas sessões
apareçam agrupadas no repositório principal.

Saiba mais na janela de ajuda: [Trabalhar com worktrees](help/worktrees).
